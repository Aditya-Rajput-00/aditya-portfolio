## 📖 About the Project

This portfolio website serves as my personal digital portfolio, designed to showcase my technical skills, projects, certifications, education, and professional journey in **Data Science, Artificial Intelligence, Machine Learning, and Data Analytics**.

Built with **React**, the portfolio emphasizes a clean user experience, responsive design, smooth animations, and easy navigation. It provides recruiters, hiring managers, and collaborators with a centralized platform to explore my work and professional profile.

The website is continuously updated with new projects, technical skills, certifications, and achievements as I progress in my learning and career.

## ✨ Features

- 🎨 Modern and clean user interface
- 📱 Fully responsive across desktop, tablet, and mobile devices
- 🌙 Dark and Light mode support
- ⚡ Smooth animations and interactive user experience
- 💼 Dedicated project showcase with GitHub and live demo links
- 🧠 Technical skills categorized by domain and technology
- 📊 Professional experience and internship timeline
- 🎓 Education and certifications section
- 📄 One-click resume download
- 📬 Contact section with social media integration
- 🚀 Fast deployment with Netlify
- 🔄 Easily customizable and continuously updated

## ⚙️ Getting Started

Follow these steps to run the portfolio locally on your machine.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Aditya-Rajput-00/aditya-portfolio.git
```

### 2️⃣ Navigate to the Project

```bash
cd aditya-portfolio
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm start
```

### 5️⃣ Open Your Browser

Visit:

```text
http://localhost:3000
```

The portfolio will automatically reload whenever you save changes.

## 🚀 Deployment

This portfolio is deployed on **Netlify**, providing fast, secure, and reliable hosting with automatic deployments from GitHub.

### Deployment Steps

1. Fork or clone this repository.
2. Push your changes to GitHub.
3. Connect the repository to Netlify.
4. Configure the build settings:

```text
Build Command: npm run build
Publish Directory: build
```

5. Click **Deploy Site**.

Every new commit pushed to the `main` branch automatically triggers a new deployment on Netlify.
