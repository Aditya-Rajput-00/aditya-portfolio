# 💻 Run Locally

Clone the repository

```bash
git clone https://github.com/Aditya-Rajput-00/aditya-portfolio.git
```

Go to project

```bash
cd aditya-portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm start
```
